This repo aims to build [scrcpy](https://github.com/Genymobile/scrcpy) with [issue 6007 workaround](https://github.com/Genymobile/scrcpy/issues/6007#issuecomment-4444559534) for Samsung using GitHub Action. For Termux package, go to my [scrcpy-6007-workaround-termux](https://github.com/Willie169/scrcpy-6007-workaround-termux) repo. You may need to keep your phone unlocked to keep a scrcpy session running.
